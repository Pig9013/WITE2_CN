# Проект мода с упрощённым китайским для War in the East 2

> **Текущая версия v1.2.2 (2026-10-28)** · [История изменений](CHANGELOG.md) · [Скачать последнюю версию](https://github.com/Pig9013/WITE2_CN/releases/latest)

## Текущая поставка

Единственная точка входа —

    mod\WitE2CN.exe

Он создаёт из каталога игры отдельную копию mod\runtime, загружает из mod\payload шрифты/overlay/словарь перевода и внедряет WitE2CN_Text.dll в эту копию. Оригинальный EXE игры, .scn и исходные CSV не изменяются.

Инструкции по запуску — в mod\README.md. Реальные операции выполняет только сам пользователь; со стороны проекта — лишь сборка файлов и статический аудит, игра и Steam не запускаются.

**Известные ограничения**: основной текст энциклопедии по-прежнему на английском (движок рендерит однобайтово; оба варианта кодовой страницы, UTF-8 и GBK, на реальной машине не сработали); `.scn` не пересобраны, поэтому подсказки по юнитам, события и сводки хода по-прежнему на английском. Остальное — интерфейс, таблицы, названия юнитов, заголовки и ссылки энциклопедии — локализовано.

**Энциклопедия на китайском (для чтения вне игры)**: основной текст выгружен в [docs/百科中文版_v1.0.md](docs/百科中文版_v1.0.md) (1,171 запись; рядом лежит DOCX).

После патча игры мод **больше не отказывается запускаться**: незарегистрированные сборки, как обычно, пытаются подключиться, а если подключиться не удалось, игра идёт на английском; патчи и сохранения не затрагиваются. Вердикт — в logs/native.log; подробности — в [CHANGELOG](CHANGELOG.md) и разделе «Обновления игры» файла mod/README.md.

**Сопутствующее руководство (не входит в сам Mod)**: официальное руководство Steel Inferno, китайская версия v1.0 · 110 страниц · текст можно выделять и копировать — см. вложение в [Releases](https://github.com/Pig9013/WITE2_CN/releases).

## Структура каталогов

    mod/
      WitE2CN.exe       Лаунчер

      payload/          Словарь runtime, шрифты, checksums, package
      runtime/          Приватная копия игры и сохранения (код не для распространения)

      build_maps.py     Сборка словаря/шрифтов/overlay/checksums
      complete_font.py  Дополняет недостающие глифы
      finalize.py       Генерирует checksums и переносимые settings
      src/              Исходники лаунчера и текстового хука

    glossary/           Глоссарий и дополнительный словарь UI
    pipeline/           Извлечение/перевод/QA/защита терминов локальным Qwen
    data/               Источники перевода и промежуточные данные
    build/              Исходники шрифтов, базовый translation.csv, брифинги кампаний, переводы сценариев в CSV
    integration/        Скрипты извлечения/генерации/аудита текста

## Переносимость

- Код не содержит жёстко прописанных путей D:\ или каталогов библиотек Steam.
- Игра ищется в порядке `--game` → settings.json → settings.local.json (запоминается автоматически) → WITE2_GAME → реестр Steam / все каталоги библиотек / перебор дисков → ручной выбор; если ничего не найдено, каталог выбирается в диалоге.
- `WitE2CN.exe --where` пишет результат поиска в logs\launcher.log; при разборе «игра не найдена» смотрите сначала туда.
- settings.json по умолчанию — пустой объект {}; game_path прописывается вручную только для установки вне Steam.
- Поле source в runtime\WitE2CN.runtime.json — лишь запись о происхождении; после переноса Mod проверяется только game_sha256.
- Скрипты сборки используют пути относительно MOD/PROJECT; зависимости от удалённого mod_full больше нет.

## Сборка (без запуска игры)

    python mod\build_maps.py
    python mod\complete_font.py
    python mod\finalize.py

build_maps.py читает готовые переводы и не обращается к модели. Сам перевод выполняет локальный Qwen в pipeline.

## Тексты горячих клавиш

Ключи интерфейса в EXE игры могут выглядеть так:

    Show Turn Summary {ctrl-s}
    Toggle Ground Support on/off {x}
    Move mode {F1}
    Zoom map in {+}

При сборке сканируются все строки EXE, содержащие {...}, и генерируется полный набор шаблонов; обрабатывать только один вид плейсхолдеров нельзя.

## Принципы очистки

Удалено: старые каталоги mod_full/mod_additive/install, старая установка с перезаписью, старый CSV swap, журналы сессий diagnostics, старые скриншоты/превью/zip, старые docs, тестовые exe/pdb/lib, снимки аудита.

Сохранено: текущий Mod, runtime (вместе с сохранениями), источники перевода, переводы сценариев в CSV, исходники шрифтов, скрипты сборки/аудита, глоссарий.

## Частые вопросы

**Лаунчер сообщает «файлы пакета локализации отсутствуют или повреждены: payload\...»**

Версии репозитория до 2026-10-25 страдали от преобразования переводов строк Git: файлы txt/csv/json в payload при коммите переводились в LF, и после скачивания их SHA-256 не совпадал с указанным в payload\checksums.json (файлы на месте, изменились только байты). Исправлено установкой -text для mod/payload/** в .gitattributes. Если видите это сообщение, удалите старую папку, скачайте последнюю версию заново и не смешивайте старые и новые каталоги.

## Проверка

Статическая проверка включает:

- заголовок W2CNMAP1 и число записей в translations.bin;
- покрытие cmap в шрифтах (0 отсутствующих глифов);
- checksums проходят для 25 файлов;
- число строк/полей, заголовок, BOM и нетекстовые столбцы CSV сценариев сверяются с исходным экспортом;
- settings.json равен {}, и лаунчер сам находит игру в Steam.

Проверку на машине выполняет пользователь; со стороны проекта игра не запускается.
