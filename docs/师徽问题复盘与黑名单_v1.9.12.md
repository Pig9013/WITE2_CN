# 师徽问题：全量复盘与黑名单（v1.9.12 周期）

> 2026-11-16。针对用户「重新全面审查此前所有尝试、把确定无用的操作记入黑名单、搞明白为什么中文一直实现不了」的要求。

## 0. 结论先行

1. **根因已定死，且与文件名无关。** 引擎把「单位显示名」拼进 `//Sym//<国码>//<名>.tga`（模板串 `//Sym//%s//%s.tga` / `//Sym//%s//%s %s.tga`），再交给贴图加载器；加载器把宽路径转 ANSI 时用的是 **CRT `wcstombs`（C locale）**，而且目标缓冲只按**字符数**分配（`字符数+8` 字节）。`wcstombs` 在 C locale 下遇到非 ASCII 立即失败 → 中文路径永远转不出来 → 文件永远打不开 → 详情页师徽空白（引擎不报错、不写日志）。
2. 所以「造一份中文名贴图副本」从原理上就不可能成功——无论副本叫 `第1装甲师.tga`、`1st 装甲师.tga` 还是别的。**这类尝试已全部作废并进黑名单。**
3. 唯一可行修法：**在加载前把中文名映射回英文原名**（等价于英文版的行为），路径其余部分不动。这个方向是对的。
4. 上一版实现之所以没生效，不是方向错，而是**补丁只挂了 8 个调用点里的前 8 个——而师徽那一个排第 246**。加载器是全游戏通用的贴图加载器，共 **256** 个调用点。这是我的实现缺陷，本轮已改。

## 1. 证据链（全部机器判定）

| 证据 | 内容 |
| --- | --- |
| 实测日志 | `mod\logs\crest.log` 全为 `C|0|0|//Sym//GE//1st 装甲师.tga`（同类还有 60th 摩托化师、89th 空军高射炮团、15th 装甲师…）：路径**完整正确**、返回 0、文件不存在 |
| 加载器 | RVA `0x44dc30`：`sub esp,0x400`（1024 字节 ANSI 缓冲）→ `call 0x4368c0` 拼绝对路径 → `call 0x4461c0`（纹理管理器，ecx = `0x1132abc`）|
| 宽转窄 | RVA `0x44b1f0`：数字符 n（`mov ax,[esi]` 逐字）→ `new(n+8)` → `push n; push src; push dst; call 0x4c310a` |
| 转换函数 | RVA `0x4c310a` = MSVC `wcstombs`：参数为空时 `errno=0x16(22=EINVAL)`（`0x4c3180` 分支），内部走 `_wcstombs_l(dst,src,n,&locale)`（`0x4c312a` → `0x4c62e2b`） |
| 无 locale 调用 | 导入表**没有** `wcstombs`/`mbstowcs`/`setlocale` → CRT 静态链接、进程停在默认 `"C"` locale |
| 缓冲不足 | 分配 `字符数+8` 字节，而 GBK 中文 1 字 2 字节 → 即使转换成功也会截断 |
| 调用点 | 全 `.text` 扫描 `call 0x44dc30` = **256** 个；师徽点 `0x3ef56e` 排名 **246**（0 基 246） |

结论：ASCII 路径「字符数 = 字节数 = 缓冲刚好」，所以英文版正常；中文路径「转换失败 + 缓冲不足」，必死。空军机徽文件名本来就是 ASCII（`1._NAGr 1.tga`），所以一直正常。

## 3. 本轮修法（唯一）

- 保留 `payload/crest_names.bin`（1,563 条：中文拼装名 → 英文原名，源自我方 CSV+OBs+词典+Sym 实存文件）。
- `install_crest`：容量 512，**对全部 256 个调用点打补丁**，日志打印 `sites=256`；任何校验失败整体放弃（游戏照常跑英文）。
- `crest_thunk`：只对 `//Sym//` 开头的路径查表改写；并把结果写 `logs\crest.log`：`S|返回码|原路径|改写后路径`（连续重复折叠，上限 4,000 行），供下一次实机判定。

## 4. 判定口径（下次运行后）

- 出现 `S|0|//Sym//GE//1st 装甲师.tga|//Sym//GE//1st Panzer Division.tga` 且返回码非 0 → 名字映射已生效，瓶颈移到 D3DX/文件系统编码（另证）。
- 第 4 段（改写后路径）为空 → 映射没命中（词典/Csv 拼装与引擎实际显示名不一致），需按 crest.log 里的原路径补映射。
- 完全没有 `S|` 行 → 钩子没生效，先看 `native.log` 的 `READY: crest loader hooked, sites=N`。
