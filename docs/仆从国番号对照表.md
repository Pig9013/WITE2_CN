# 仆从国番号对照表（本国语言 / 英文 / 中文）

> 起因：游戏里仆从国部队一律用英文缩写（Rum. / Hun. / Ital. / Fin. / Slov.），
> 但它们本来有自己的番号体系，直接按英文转手会丢掉「师/旅/军」的真实层级。

编号 P-xxx；语料验证 = 该中文在本机语料中的出现次数。

## 六、汉语语序

仆从国部队一律国名在前：罗马尼亚第3集团军、匈牙利第2集团军、意大利第8集团军、
芬兰第2军、斯洛伐克快速师。原来的「第3罗马尼亚集团军」式写法已全部改为国名前置
（202 条，脚本 integration/fix_ally_designations.py）。

## 八、尚未解决

- 罗马尼亚 vânători de munte（山地猎兵）、匈牙利 honvéd 等民族性军语，
  中文文献译法不统一（山地猎兵 / 山地兵；洪韦德 / 国防军），本表取描述性译法。
- 芬兰 ryhmä（战斗群）、osasto（支队）等临时编组名，语料里没有稳定译法。
- 克罗地亚乌斯塔沙部队的建制名尚未逐条核对。
