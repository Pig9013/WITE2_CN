## 四、结论

1. 装甲车辆的德军编号体系（740/731/734/735/739/744/747 + 国别字母）核对无误，现有「型号+坦克」的译法可以保留。
2. 自行炮的 GW 不是 Ground War，而是 Geschützwagen（自行炮架）；两条最严重的误译已订正为「自行榴弹炮」。
3. 俘获火炮的中文名统一为「口径毫米 + 德军编号 + 炮种」，不再混用「捕获/缴获」。
4. 仍待核：88mm FlakM31/M39(r) 的原厂型号（苏制 85mm 52-K 的说法需要再查一份德军俘获火炮清单）；75mm FK97/38(f) 与 Pak 97/38 的区别。
