## 七、专名不逐字直译

番号、部队名、地名里有很多「看起来像普通词」的专名，逐字直译会变成另一回事。判据只有一条：**它是不是专有名词**。

| 编号 | 原文 | 错法 | 正解 | 理由 |
|---|---|---|---|---|
| T-220 | 3rd Gennaio / 23rd Marzo | 1月3日 / 3月23日 | 3 Gennaio / 23 Marzo | 意大利黑衫军军名按纪念日命名，是番号不是日期；直译成日期读者反而不认 |
| T-221 | 1st Sep. / 507th Sep. | 9月1日 / 第507步兵师 | 第1独立 / 第507独立 | Sep. = Separate（独立），不是 September；旧译既错解缩写又凭空补了「步兵师」 |
| T-222 | Waren / Siegen | 物资 / 胜利 | 瓦伦 / 锡根 | 德语城镇名恰好也是常用词，按字面译成物资、胜利就成了笑话 |
| T-223 | Agri / Aguilas / Airasca | 农业区 / 鹰群 / 空袭中 | 阿勒 / 阿吉拉斯 / 艾拉斯卡 | 土耳其、西班牙、意大利地名，按字面义译完全失去地名功能 |
| T-224 | Allier / Alle | 盟军 / 所有 | 阿列河 / 阿勒 | 法国河流与地名 |
