# War in the East 2 中文 Mod v1.9.10

> 从 v1.9.9 升级上来的玩家，这一版是**一次查漏补缺**：把"同一个英文串被译成几种中文"从 1,816 组压到 1,308 条，并把上一轮自己造出来的脏值清掉；另外修好了 Steam 装 DLC 后主菜单整页变黑。
> 过程与判据见[同词多译审计](docs/同词多译审计_v1.9.10.md)、[扫尾审计](docs/扫尾审计_v1.9.10.md)、[主菜单黑屏排查](docs/主菜单黑屏排查_v1.9.10.md)。

## 这次修好了什么

- **德国空军"中队"和"大队"不再同名。** `1./JG 51` 与 `I./JG 51` 曾都显示"第51战斗机联队第1大队"——`N./` 是 Staffel（中队），`I./` 是 Gruppe（大队），两条是不同层级的建制。共修正 **299 格**，覆盖 21 个文件 / 12 个剧本。
- **地面装备型号不再被截断。** `Crusader I` 曾译"十字军行动"、`Grant CDL` 曾只剩"格兰特"、`Tetrarch CS` 曾只剩"特特拉奇"，共 8 键 / 96 格改为"十字军I""格兰特CDL""特特拉奇CS"。
- **SS 番号整族定口径。** 775 格 / 60 键：`1st SS` 曾写成"第1党卫军装甲师"（缺"警卫旗队"这类部队名）、`X SS` 与 `XI SS` 的罗马数字曾被折成阿拉伯数字、`II SS` 曾直接变成"第二装甲师（党卫军）"。现统一为"第N党卫军 + 部队名"，师/军分明。
- **地名不再被当普通英文词意译。** 262 条：`Zwischenahn` 曾译"杂种"、`Immola` 曾译"焚烧"、`Guestrow` 曾译"来宾行"、`Charmy Down` 曾译"夏缅陷落"、`Bougie` 曾译"灯芯绒"、`Torn` 曾译"撕裂"。共 **8,194 格**（语料 888 + 场景表 7,306），并建立可复核正译表 `glossary/place_name_canon.csv`（262 行，逐条注明依据：维基 98 / 规则 122 / 订正 32 / 共识 10）。
- **部队名按编制层级正名。** 100 键 / 429 格：`OB West` 曾译"西方"（实为西线集团军群级）、`Western` 曾与"西线"混用（实为西方面军）、`310th RVGK` 曾译"集团军属炮兵团"（实为最高统帅部预备队）、`DXXXV`/`DV`/`LI Mountain` 的罗马数字曾被丢。正译表 `glossary/unit_name_canon.csv`。
- **场景表显示层的脏值清零。** 游戏里真正显示的文本在场景 CSV，而此前所有守卫只查字典——于是漏下了 **522 个脏单元格**：LLM 把翻译过程写进了值里（`巴尼奥奇czy 不在翻译范围内…`）、拉丁残片（`切赫owitz`、`红oub`）、缩写误读（`AAMG`→"AA 卡车"，实为高射机枪）。新工具按英文源行对齐改写，并加通用残片守卫。
- **回滚上一轮自己造的错。** SS 批次曾用"按中文值全局替换"实现，误伤苏军 `2/13 IAP-KBF`、`2/20 IAP` 共 13 格（被改成"第13党卫军第2营"）；已还原并删掉两条错键。
- **主菜单黑屏（不是汉化问题）。** Steam 装《钢铁炼狱》DLC 后，私有副本 `mod\runtime` 比游戏目录少 **150 个文件**（主菜单图 `MainMenuSteelInferno.bmp`、116 张事件图、31 个 DLC 剧本文件、2 份手册），而旧启动器只在**主程序哈希**变化时同步——DLC 没动 EXE，于是永远不补。启动器已改为按**内容签名 + 缺失探针**同步，`--prepare` 可离线补齐，实测补 171 个文件、缺失 0、`Dat\Art\Gui` 338/338。

## 这次变了什么

- **词典 72,251 条**（v1.9.9 是 72,254；减 3 条：两条被误伤的苏军航空团键、一条译文回退英文变成恒等键）。
- **分层冲突 1,816 → 1,308 条**：其余是"片段 vs 全名""罗马数字 vs 阿拉伯数字""空格/星号差异"这类同一个指称的无害差异，逐条改反而会破坏一致性。
- **构建链 12 → 13 道守卫**：新增 `Cell-dirt guard`（场景表显示层脏值与残片）、`SS-scope guard`（英文源无 SS 却出现"党卫军"即失败）、`Staffel guard`、`Semantic/Place-name/Unit-name guard`；守卫失败即拒绝构建。
- **DLC 与无 DLC 都适用**：没装 DLC 的玩家文件本来就少，同步按"缺什么补什么"处理，不会因缺 DLC 文件报错；已装 DLC 的玩家第一次启动会自动补齐。
- **兼容性**：存档、剧本、游戏本体都不受影响；删掉 mod 文件夹即回到英文。四语言包（简/台/港/澳）各 72,251 条、缺字 0；字体 2,433 / 2,267 / 2,269 / 2,269 字形；payload 92 个文件校验全通过。

## 我们没做到什么（如实说明）

- **prose 34 条不处理**：事件正文被截断，两条候选译文都不完整，要读原文才能判断哪条对，不适合规则批量改。
- **登记不修的老账**：`OBs` 的国别前缀 240 个不同值（`BR Air Base` 曾译"布列斯特机场"，BR 是英国）、英国地方师（Type 2820，`2nd Belfast` 曾译"第二班诺菲"）、意大利命名师（Type 1711，`16th Pistoia` 曾译"第16摩德纳师"）、`March FF DMC/DMA` 26 格、`III/FAS` 3 格、1941 剧本的 1,257 行空军大队未译。
- **纯型号口径未定**（P2）：Ground 64 条 / Aircraft 498 条只含型号的条目，是"保留原文"还是"译出类别"尚未定案。
- **DLC 内容未汉化（下一批）**：DLC 新增的 11 份剧本简介（`Dat\Scen\*.txt`）与 7 个剧本的单位/事件/地名表还没做；现有 12 个剧本的汉化不受影响。
- **未进游戏核对**：工程侧按铁律不启动游戏，离线自检只验证语言包完整性与私有副本完整性。**需要你进游戏目视确认**：主菜单背景是否恢复、`1./JG 51` 与 `I./JG 51` 是否分开、地名是否还认得。

## 怎么看某个游戏版本行不行

看 `mod/logs/native.log`：出现 `READY` 表示该游戏构建已接入；出现 `FAILED` 会以英文运行，存档与补丁不受影响（未登记构建不会拒绝启动）。
私有副本是否完整看 `mod/logs/launcher.log`：出现"检测到游戏资源有变化…缺少 N 个文件"并随后"准备完成"，即已自动补齐。
