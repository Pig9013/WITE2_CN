# 番号与缩写术语表（WitE2 简中）

> 本文是 glossary/designations.py 的说明书与对照表；表格部分由
> integration/export_termbase.py 从代码生成，避免文档与实现脱节。

## 一、为什么要有这张表

游戏里的部队番号不是英文，是**英文转写的俄文/德文缩写**：

| 游戏里写的 | 它到底是什么 | 早期译文（错） | 现在 |
|---|---|---|---|
| 6 IAK PVO | 6-й истребительный авиационный корпус ПВО | 6 IAK PVO防空军 / 8独立航空兵防空师 | 防空第6歼击航空军 |
| 101st RVGK | 101-й гаубичный артиллерийский полк РВГК | 第101近卫步兵师 | 最高统帅部预备队第101榴弹炮团 |
| 1 AOK | Armeeoberkommando 1 | 第1方面军群 | 第1集团军司令部 |
| 2 PAOK | Panzerarmeeoberkommando 2 | 2 帕奥克军 | 第2装甲集团军司令部 |
| FBD 1 | Feldeisenbahn-… 1 | 第1快速反应旅 | 第1野战铁道局 |
| 5th O.T. | Organisation Todt 第5建筑营 | 第五摩托化步兵师 | 托特组织第5建筑营 |
| 11 IAP-ChF | 11-й иап ВВС ЧФ | 第11歼击航空团（丢了舰队） | 黑海舰队第11歼击航空团 |

根子上的问题：这些缩写只有回到**原语**（俄文/德文）才有确定含义。
按英语语感去猜，就会把 ПВО 当"防空军"、把 РВГК 当"近卫"、
把 *Oberkommando*（司令部）当成苏联的"方面军"。所以术语表必须带原语全称。

## 二、译名规则

1. **修饰语在番号前**：近卫 / 防空 / 预备队 / 舰队 都放在「第 N」之前。
   12 GIAP PVO → 防空近卫第12歼击航空团；1 GBAK → 近卫第1轰炸航空军。
2. **建制序**：第 N + 兵种 + 建制。6 IAK → 第6歼击航空军。
3. 苏联空军建制统一用「航空军 / 航空师 / 航空团」，不用「航空兵军 / 航空兵师」。
4. **ПВО**（противовоздушная оборона，对空防御）：作军种是「国土防空军」，
   作部队隶属关系（иак ПВО）是前缀「防空」。**不译"防空军"**——那会把
   一个兵种当成建制级别，闹出"第6防空军"这种不存在的单位。
5. **РВГК**（Резерв Верховного Главнокомандования）= 最高统帅部预备队。
   它是**统帅关系**，不是近卫、不是兵种；101st RVGK 的真实编制由 OB 表决定
   （榴弹炮团 / 加农炮团 / 大威力炮兵营 …），译名要连编制一起写。
6. **AOK / PAOK** 里的 *Oberkommando* 是「司令部」，不是「方面军」；
   *Panzerarmee* 是「装甲集团军」。
7. **舰队后缀**必须落地：ЧФ 黑海舰队、КБФ 波罗的海舰队（全称红旗波罗的海舰队）、
   СФ 北方舰队、ТОФ 太平洋舰队。
8. **缩写不留在中文里**：译文里不应再出现 IAK / PVO / RVGK / AOK / PAOK 这类
   拉丁缩写（正文叙述里需要括注原文的除外）。

## 四、尚未完全解决

- **FBD** 的德文全称有 *Feldeisenbahn-Baudirektion*（建筑）与
  *Feldeisenbahn-Betriebsdirektion*（运用）两说；游戏里是修路单位，
  中文取中性的「野战铁道局」，不冒险写成"建筑局"。
- RHG 译「后方军区」是简写；严格说是"集团军群后方地域"，
  但作为番号前缀太长，取简。
- 罗马尼亚、匈牙利、意大利、芬兰、斯洛伐克部队的**本国语言**番号
  （如 Divizia 1 Infanterie、1. hegyidandár）游戏里一律用英文缩写
  （Rum. / Hun. / Ital. / Fin. / Slov.），本表按英文缩写处理。
