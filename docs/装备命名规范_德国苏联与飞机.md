# 装备命名规范：德国装甲、苏联装备与飞机

- 项目：WITE2 中文汉化（WitE2_CN_repo）
- 日期：2026-11-03
- 范围：Ground.csv（地面装备）、Aircraft.csv（飞机）、Devices.csv（武器/小队）
- 原则：**型号码保留原文，类型词按原语，译名以文献与中文语料用法为准；不用英文常用词义直译专名。**

|---|---:|---:|---:|---|

当前问题不是「没翻译」，而是**同一类装备有四五种写法**：

- 德军坦克：装甲Ib型 / II型C型装甲车 / 装甲38(t) / 四型装甲车 / 豹式坦克 D 型
- 德军歼击车：坦克歼击车 IV型 / 歼击坦克38追猎者 / 猎虎坦克（Jagdpanther 与 Jagdtiger 撞名）
- 苏军：T-26 型 1931 式 / T-34坦克 M1940 / T-34坦克/85 坦克 1944型 / 苏-57
- 飞机：Ar 234B-2→阿AFF234B-2型；Do 215B-4→道215B-4；CR.42→指挥官报告 CR.42 阿芙柯42型

## 2. 文献依据

### 2.1 德军装备

| 文献 | 关键内容 | 用途 |
|---|---|---|
| TM 30-506（1944） | Panzerkampfwagen = tank；Sturmgeschütz = assault gun；Panzerjäger = antitank；Panzer = armor; tank | 类型词基准 |
| Niehorster, German WWII Organizational Series, vol. 3/5（2010）p.81–83 | Panzerjäger 38(t) Ausf. H = self-propelled antitank gun；Jagdpanzer 38 = light tank destroyer；Jagdpanzer IV；Jagdpanther | 车族分类 |
| Order of Battle of the German Army（1944）p.71–73 | Panzerjägerabteilung = antitank battalion；Panzerzerstorer Kompanie = antitank rifle company | 编制与装备对应 |
| TM-E 30-451（1945）p.139/210 | Panzerzerstörer Bataillon 装备巴祖卡；Panzerschreckabteilung | 反坦克部队 |

### 2.2 苏军装备

| 文献 | 关键内容 | 用途 |
|---|---|---|
| FM 100-2-3（1991） | 苏军装备以「型号+编号」为正式名（T-54、T-55、T-72），不改意义 | 型号码保留 |
| The Red Army Handbook 1939–1945（Zaloga/Ness） | T-34/76、KV-1、SU-76 等型号体系 | 型号与变型 |
| Soviet Army Order of Battle（Argüelles） | 苏军坦克/机械化军装备表 | 装备与编制对应 |

## 3. 命名规则

### 3.1 德军坦克与自行炮

| 原文模式 | 译法 | 例 |
|---|---|---|
| Panzer <I–IV><变型> | <中文数字>号<变型>型坦克 | Panzer IVh → 四号H型坦克 |
| Panzer <I–IV> | <中文数字>号坦克 | Panzer III → 三号坦克 |
| Panzer 35(t)/38(t) | 35(t)/38(t)坦克 | Panzer 38(t) → 38(t)坦克 |
| Panther <A–G> | 豹式<变型>型坦克 | Panther G → 豹式G型坦克 |
| Tiger / King Tiger | 虎式坦克 / 虎王坦克 | — |
| Stug III<变型> | 三号<变型>型突击炮 | Stug IIIg → 三号G型突击炮 |
| StuH42 | 三号42型突击榴弹炮 | StuH 42 装于三号底盘 |
| Sturmpanzer IV | 四号突击坦克 | 不是「突击炮」 |
| Jagdpanzer IV | 四号坦克歼击车 | — |
| Jagdpanzer 38 Hetzer | 38(t)“追猎者”坦克歼击车 | — |
| Jagdpanther / Jagdtiger | “猎豹”/“猎虎”坦克歼击车 | 不得都译「猎虎」 |
| Ferdinand / Elefant | “斐迪南”/“象式”坦克歼击车 | — |
| Nashorn | “犀牛”自行反坦克炮 | 不译「纳索恩」 |
| Marder I/II/III | <数字>号“黄鼠狼”自行反坦克炮 | 语料通行「黄鼠狼」 |
| Wespe / Hummel | “黄蜂”/“野蜂”自行榴弹炮 | — |
| 俘获车辆 | 保留原型号 + 坦克/突击炮 | Panzer B-2 740(f) → B-2 740(f)坦克 |

### 3.2 苏军装备

| 原文模式 | 译法 | 例 |
|---|---|---|
| <型号> M<年份> | <型号> <年份>年型 | T-34 M1941 → T-34 1941年型 |
| T-34/85 M1944 | T-34/85 1944年型 | 不再写「T-34坦克/85 坦克」 |
| KV-1s | KV-1S | 统一大写 S |
| SU-/ISU-/IS-/KV-/BT-/T- | 保留拉丁型号 | SU-57 就是 SU-57，不是「苏-57」 |
| M4A2 Sherman | M4A2“谢尔曼” | 不译「詹姆斯」 |
| M3A1 Stuart | M3A1“斯图亚特” | 不译「史塔克」 |
| Matilda/Valentine/Churchill | “玛蒂尔达”/“瓦伦丁”/“丘吉尔”+型号 | — |
| BA-10 Armored Car | BA-10装甲车 | — |
| <型号> Chassis | <型号>底盘 | — |

### 3.3 飞机

| 规则 | 例 |
|---|---|
| 德国飞机保留拉丁型号码，不译厂名 | Do 17Z-2，不写「道尔尼耶 Do 17Z-2」 |
| 型号后缀照录 | Bf 109G-6、Fw 190A-5、Ju 87D |
| Type/Series 译「型/系列」 | I-16 Type 18 → I-16 18型 |
| Rcn 译「侦察型」 | SB-2 Rcn → SB-2 侦察型 |
| 苏机可用通行中文名 | 伊尔-2、佩-2、图-2、雅克-9、拉-5、米格-3 |
| 不得按词义直译 | Mustang≠必须，Meteor≠气象，Typhoon≠台风行动，Battle≠战斗 |

## 5. 仍然存在的问题

1. **飞机长尾**：已按 3.3 规则重排 509 条——德国保留拉丁型号码，苏军主要机型用中文，西方只保留主要机型中文名，其余一律拉丁。意大利/芬兰的冷门机型改回拉丁原名，避免继续误译；如要恢复中文昵称，需逐型核对。

## 6. 审计告警的含义与处理（本次已清零）

integration/audit_scenario_csv.py 的口径是：**译文 CSV 与源 CSV 逐格对比，只有 title/text（及 Name 等白名单文本列）允许不同**。

告警 row 252 col 88 ('extra88') changed unexpectedly 的意思是：

- 该行有 295 列，前 18 列是表头字段，后面是**事件脚本参数**（城市名、条件、跳转等）；
- 第 89 列等 extra 列本应与源文件完全一致，但被翻译成了中文，且出现 UTF-8/CP1252 双重编码（é›…ç½—...）；
- 这类列一旦被改，事件条件可能匹配不到城市/ID，属于**会坏存档/坏事件**的结构性缺陷。

处理：

1. 新增 integration/restore_nontext_columns.py：对每个场景 CSV，只保留白名单文本列，其余列逐格恢复源值，表头也恢复英文；
2. 本次恢复 **10 个文件、168 格**（GameEvents 等）；
3. 重新审计：**188 文件 / 398,480 行，0 失败**，19 条仅为「源文件 cp1252→译文 UTF-8」的编码归一化警告，不影响内容。

纪律：以后任何批量翻译都不能碰非文本列；新增文本列必须先进审计的 SPEC 白名单。
