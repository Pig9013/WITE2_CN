# 切换道路显示/隐藏失效排查（v1.9.15，2026-11-17）

## 现象

玩家点地图状态栏的「道路系统」按钮（原版此处道路以红色显示），现在没有任何可见变化，
看起来像按钮失效。原版正常。

## 结论

不是按钮失效，是**道路图块路径被本地化成了中文目录**，引擎按名字找不到图块后静默跳过
（不报错、不写日志）。

### 证据链

1. 按钮与提示文案本身正常：词典里 `Road System  {ctrl-r}` → `道路系统 (ctrl-r)`、
   `Toggle Roads on/off {ctrl-r}` → `切换道路显示/隐藏 (ctrl-r)`，热键后缀都在。
2. 引擎拼图块路径的模板（EXE 0x5b8378，UTF-16）：
   `//Tiles//ROAD//%s//%s_%3.3d.tga`，两个 %s 都取「路面质量」令牌。
3. 令牌是紧挨模板的独立全大写 ASCII 串：`POOR` @0x5b82b0、`AVERAGE` @0x5b82bc、
   `GOOD` @0x5b836c。
4. 美术目录 `Dat\Art\Tiles\ROAD\` 下正好只有 AVERAGE、GOOD、POOR 三个子目录
   （POOR 只有 EmptyCheck.txt，原版本就没有 POOR 路面图）。
5. 同一个令牌会被引擎当普通字符串送进本地化查表函数——v1.9.7 小河消失
   （`//Tiles//RIVER//%sR%d_%3.3d.tga` 的 `MINOR//` 被译成「次要」）是同一机制。
6. 词典里没有 `POOR`/`AVERAGE`/`GOOD` 精确键（v1.9.7 审计时已清出），但钩子的
   **归一化第二索引**（`mod/src/text_hook.c:128-139` normalize_key，去空白 + 转小写；
   `text_hook.c:250-269` translate 在精确未命中时走 norm_lookup）把它们接回了界面词：
   `Poor`→差、`Average`→平均、`Good`→良好。路径随即变成
   `//Tiles//ROAD//平均//AVERAGE_001.tga` → 文件不存在 → 引擎跳过。
7. 归一化索引是 v1.9.7 之后才加的，正是它把当时已清掉的一批美术令牌全部复活。

### 受影响的同类令牌（全大写、同时是美术目录名、且能用归一化撞上界面词）

AVERAGE、CITY、CUSTOM、FACTORY、GOOD、IMPASS、IMPASSABLE、PO、POOR、SAND。
其中 AVERAGE/GOOD/POOR 就是道路图块；CITY/SAND/IMPASSABLE/CUSTOM 是地形图块目录，
同机制下也会画不出来（只是此前没人报告）。

## 处置

1. `mod/build_maps.py` 新增**美术令牌钉死层**：读 `glossary/art_tokens.json`，凡是
   全大写、当前没有精确键、却存在「忽略大小写/空白后等价」词典键的美术令牌，写成
   **恒等条目**（值=原文）。精确命中优先于归一化索引，引擎拿回的就是 `POOR` 本身。
   - 不删界面词：`Poor`/`Average`/`Good`/`City`/`Sand` 的首字母大写形式照旧翻译，
     只有全大写令牌被钉死。
   - 本轮钉死 10 条：`AVERAGE<-Average, CITY<-City, CUSTOM<-Custom, FACTORY<-factory,
     GOOD<-Good, IMPASS<-Impass, IMPASSABLE<-Impassable, PO<-Po, POOR<-Poor, SAND<-Sand`。
2. `mod/finalize.py`：
   - Art-path guard 允许「恒等条目」（值=原文），仍拒绝真译文混进美术令牌键；
     报告里单列 `identity pins`。
   - 新增 **Norm-collision guard**：全大写美术令牌若既没有精确条目、又存在归一化等价
     的词典键，直接拒绝构建。以后美术目录或词典变了，构建期就会拦住，不必再等玩家报障。
3. 未改钩子 DLL（不重编、不换注入方式），纯词典 + 构建期守卫，可回滚。

## 验证（离线）

用安装目录里的 `payload\translations.json`（72,529 条）复刻 translate() 的两级查表：

| 源串 | 结果 | 命中方式 |
| --- | --- | --- |
| `POOR` / `AVERAGE` / `GOOD` | 原文 | exact（钉死） |
| `Poor` / `Average` / `Good` / `City` / `Sand` | 差 / 平均 / 良好 / 城市 / 沙地 | exact |
| `M o s c o w` / `Moscow` / `MOSCOW` | 莫斯科 | exact / exact / norm（地图标签归一化未受影响） |
| `Mar` / `GENM` / `Load` / `Pen` | 3月 / 少将 / 载重 / 穿甲 | 回归未变 |

构建链全绿：build_maps（72,519→72,529 条，9,453,202 B）→ complete_font（2,447 字形）→
build_variants（四包缺字 0）→ finalize（Art-path guard OK、Norm-collision guard OK、各守卫 OK）
→ publish（复制 11 文件，校验通过，安装目录版本 1.9.15）。

## 还需实机确认

- 点「道路系统」按钮，道路应恢复红色显示；再点一次应恢复原状。
- 顺带看：城市（CITY）、沙地（SAND）、不可通行（IMPASSABLE）、自定义图块（CUSTOM）
  这类地形图块是否正常——它们与道路同属「钉死」名单。
- 若道路仍无变化，说明问题不在图块令牌，需要给钩子加一次全量 trace 再定位
  （那就要重编 DLL，属另一条路线）。
