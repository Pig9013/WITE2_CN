# Release v1.9.22（2026-11-19）

## 这次修好了什么

**「可用航空作战群」列表为空——这次真修好了。** 上一版（v1.9.21）已经把这些名字钉成英文原文，玩家复测列表仍然一行都没有；这一版找到了差在哪。

引擎不是拿文本比，而是认**名字对象本身**。v1.9.21 的恒等钉死把词典池里的一份英文**副本**交回去：文本一样，但那已经是另一个字符串对象，面板筛选照样对不上，每一行在取文字之前就被滤掉。

修法：`WitE2CN_Text.dll` 增加**常驻名称守卫**——凡以 `Luftflotte`、`Luftwaffe`、`Flieger` 开头的名字，本地化函数直接返回**调用方自己传进来的那个字符串**，不查表、不复制。带兵种后缀的部队名（`Luftwaffe Field Division`、`Luftwaffe Flak Abteilung` 等）仍照常翻译，不会整条变英文。

顺带修好的：

- 诊断日志能看中文了：以前非 ASCII 一律写成 `?`，凶手串根本认不出来（上一轮就卡在这），现在按 UTF-8 输出「源串 -> 译文」。

## 怎么看某个游戏版本行不行

- 启动器标题显示 `1.9.22` 即为本版。
- 启动后看 `mod\logs\native.log`：应出现 `addr overrides: 8`、`addr skips: 5`、`AOG identity pins: 612/612`；打开「空中指令设置」面板后，日志里应出现 `TRACE ... guard en "Luftflotte 4"`，紧接着是 `%d %s`、`(E)`、`++` 这类行文本请求。
- 游戏打补丁后仍不拒绝启动：接入失败就以英文运行，存档与补丁不受影响。
- 如果某个剧本的列表又空了：先看该面板标题是不是中文；把 `mod\logs\native.log` 末段发来即可（trace 已能读中文）。
