# Release v1.10.4（2026-11-19）

## 这次修好了什么

**三处界面误译**，都是玩家截图报上来的：

1. **空军面板「天气」行显示「非俄罗斯部队」。** `Fair` 在 EXE 里只有一条（`0x52a2c0`），同块依次是 `Night`、`Poor`、`Fair`、`Good`、`Excellent`、`Medium`、`High`、`Ignore`，附近还有 `Minimum Weather`（`0x52a0b8`）——这是**飞行最低天气档**，跟民族/部队无关。v1.6.3「EXE 界面字符串第二轮」批量复用旧译时按「大小写/标点归一」匹配，把 `Fair` 接到了别处的「非俄罗斯部队」，同批的 `> Fair` 一起中招。本版两条都改「一般」，与同块的 Poor=差、Good=良好、Excellent=优秀 对齐。
2. **生产表表头「容量」「建造」。** `Capacity`（`0x53f28c`）与 `Built`（`0x5c2ad4`）字面不算错，但在这张生产表里分别是产能与建成数两列（列内是 311 / 569 / 610 与 0），改「产能」「已建成」。
3. **生产分区标题「特殊技能」。** `____ SPECIAL ____`（`0x5c3904`）同块是 `____ MANPOWER ____`、`____ GROUND ____`、`____  AIR   ____`、`____ CAPTURED ____`，其后紧接 `Production Charts`——生产界面的五个分区标题；旧译把「工业」读成了「技能」，改「特别工业（其他工业）」。

## 这次变了什么

- `glossary/reference_overrides.json` 的 ui 组：`Fair`、`> Fair` 改「一般」（4667 → 4671 条，新增 `Capacity`、`Built`、`____ SPECIAL ____`、`____ special ____` 四条，各带 EXE 偏移作注）。
- 源行同步：`data/translations/ui_ops.zh.jsonl`、`ui_extra.zh.jsonl`、`ui_14b.zh.jsonl` 及 `.qa` 副本、`build/translation.csv`、`mod/assets/translation.csv`；`glossary/master_overrides.json` 重生成 6,143 条。
- 词典仍 **74,489** 条；四语言包各 74,489 条、缺字 0；22 道守卫全过；checksums 125 条随发布重新生成。
- **没动** `SPECIAL` / `Special` / `special` 三个裸键：它们在 EXE 里紧挨 `AvailMonth`/`MaxCmd`/`airDivLink` 一类字段名，是数据字段而非界面标题（生产表标题用的是带下划线那条），显示场景未证实，不在本次范围内顺手改。

## 怎么看本版生效

- 启动器标题显示 `1.10.4` 即为本版（游戏主界面右下角版本号不变，仍是游戏自身的 1.0.5.02）。
- 空军单位面板「天气」行：最低天气档显示「一般」，不再出现「非俄罗斯部队」；同一行的「当前天气」仍按 极差 / 差 / 一般 / 良好 / 优秀 显示实时值。
- 生产界面表头：产能、受损、储备池、已建成、单位；分区标题：兵力管理、特别工业（其他工业）、地面作战、空 军、被俘。
