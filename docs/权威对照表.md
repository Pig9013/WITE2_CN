## 二、正式出版物单列统计

把「书」和「兵棋规则书/游戏手册」分开看，结论会清楚很多。下表只统计五部中文战史（《泥足巨人》《东线》《斯大林格勒三部曲》《焦土》《地图上的二战·东线战场》）。

| 书 | 字数 | 近卫第N | 第N近卫 | 防空第… | 第N防空… |
|---|---|---|---|---|---|
| 泥足巨人 | 46 万 | 0 | 0 | 7 | 1 |
| 东线 | 38 万 | 24 | 407 | 0 | 0 |
| 斯大林格勒1上 | 34 万 | 19 | 0 | 1 | 0 |
| 焦土 | 49 万 | 30 | 0 | 0 | 0 |
| 地图上的东线 | 37 万 | 107 | 0 | 0 | 0 |
| **合计** | | **180** | **407** | | |

读法：按**书**算，三比一——《焦土》《斯大林格勒三部曲》《地图上的二战·东线战场》一律「近卫第 N」；朱世巍《东线》全书统一「第 N 近卫」。按**次数**算反过来，因为《东线》一本就占了四百多次。本 Mod 取「近卫第 N」，与多数出版物一致；若要与游戏手册写法统一，把 designations.guards_first 反向跑一次即可。

结论：
- **语序**：证据并不一致，必须按来源分开看——
  - 正式出版物：见上表，焦土/斯大林格勒/地图上的东线用「近卫第 N」，朱世巍《东线》用「第 N 近卫」。
  - WitE2 官方中文手册：「第 N 近卫步兵师」这一类写法更多。
  - 本 Mod 取「近卫第 N」，与正式出版物一致；若要与游戏手册完全统一，只需把 designations.guards_first 反向运行一次。
- **航空兵 vs 航空**：出版译本用「歼击航空兵师/团」；WitE2 官方中文手册用「歼击航空师/团」。游戏内显示取后者，长度也更适合计数器。
- **防空**：语料里「第 N 防空」多为英美防空营/集团军；苏军 ПВО 单位在《泥足巨人》附录里写作「防空歼击航空兵团/防空师/防空旅」——即「防空」作前缀。故「防空第6歼击航空军」与原书构造一致。
