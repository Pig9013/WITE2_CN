# v1.9.17 —— 支援单位窗口与部队检索修好 · 同串异义按地址拆分 · 百科表恢复原版

**发布日期：2026-11-18** · 适用于 War in the East 2 1.0.5.02 · [更新日志](https://github.com/Pig9013/WITE2_CN/blob/main/CHANGELOG.md) · [下载](https://github.com/Pig9013/WITE2_CN/releases/latest)

## 一句话

v1.9.16 之后的三批修复合入本版：「分配支援单位」窗口的英文列头补齐、部队一览检索框不再被误翻成「近卫」、战斗详情表里 `DIS`/`TR` 这类「同一串在不同窗口含义不同」的问题改成按字符串地址分译，另外三张百科表恢复成游戏原版。

## 这次修好了什么

- **「分配支援单位」窗口**：列头 `RG`→距离、`CITY`→城市、`OHQ`→作战司令部，另补 `Ammo/Need`、`Supply/Need`、`Fuel/Need`、`Assign AA/CONST Unit to '%s'`，以及把高射炮调进/调出城市时的两条行政点提示（手册 21.5 Anti-Aircraft Units）。
- **部队一览检索框**：以前输入 `guard` 会被翻成「近卫」，而列表数据本身仍是英文，于是搜不到任何近卫部队。原因是文本钩子的「忽略大小写」第二索引把任何位置的 `guard` 都接了进来。现在第二索引只对三种串生效（含空白 / 全大写 / 源串落在游戏主模块镜像内），堆缓冲区里的小写单词原样返回，检索恢复。词典里 246 条全小写键的精确匹配行为不变。
- **同串异义按地址拆分**（v1.9.16 已知限制的第一条）：文本钩子新增地址特化层，比对源串指针（`source − image_base`），命中就返回该处专用译法，同一串在别处不受影响。本版 8 条：`CITY`×2→城市、`CUSTOM`→自定义、`DIS`×4→紊乱（地面损失 / 地面战斗 / 空战 / 要素表）、`TR`→运输（飞机类型码）。于是战斗详情表里 `DIS` 显示「紊乱」，单位状态与撤编筛选里仍是「解散」。
- **构建期防漂移**：出包时按 RVA 回读游戏 EXE 的字面量，与登记的原文不符立刻中止（`Address sources verified: 8`），避免游戏更新后地址错位、在错误的串上改错字。
- **百科表恢复原版**：`Dat\Info` 的 `deviceInfo` / `groundInfo` / `leaderInfo` 三张表 id 列全是 0，之前被按 id 索引覆盖成同一句正文（4 / 2 / 2 行各只剩一种）。现在这三张表与 `unitInfo.csv` 一样**整表复制游戏原版字节**进覆盖层，`restore_unit_info.py --check` 逐字节核对。
- **publish 清理陈旧副本**：覆盖层只写不删，安装目录里语言包变体的坏副本会一直留着；现在发布时删除仓库中已不存在的变体文件（本轮 9 个）。

## 这次变了什么

- 版本 1.9.17；词典 **72,566 条**（v1.9.16 为 72,550）；字体 2,447 字形，四套语言包缺字 0；构建链 **19 道守卫**；checksums 125 条全通过。
- `WitE2CN_Text.dll` **重编**：209,408 → **99,840 字节**，sha256 `0038EA911D3FDFFAF61EC169458D924BE45E03797A935D978870B45315FE4AC7`。新增两种日志行：`ADDR override`（地址特化命中）与 `NORM blocked`（第二索引被拦下）。启动器会随包更新该 DLL，不需要手动替换。
- 新增数据文件 `glossary/addr_overrides.json`（8 条，格式「译文 / 原文 / 说明」）。
- 不改游戏 EXE、`.scn`、原 CSV、贴图或存档；删除 mod 文件夹即回到英文。

## 怎么看某个游戏版本行不行

看 `mod\logs\native.log`：

- `READY: hooked 2 call site(s); lookup at text+0x...` —— 文本钩子已接上；出现 `FAILED` 表示该游戏构建接不上，游戏以英文运行，存档不受影响。
- `ADDR override: ...` —— 地址特化生效（`CITY`、`DIS`、`TR` 等按窗口分译）。若某窗口里这些词仍是英文、且没有该行，说明引擎在那里先把字符串复制进了缓冲区，地址特化拿不到原始位置——那种情况只会退回英文，不会误译。
- `NORM blocked: ...` —— 第二索引按预期拦下了非界面串（如检索框里的 `guard`）。

## 已知限制（本版未解决，如实说明）

- 地址特化只在引擎把字面量**原地**传进本地化函数时生效；经缓冲复制的地方退回普通词条（显示英文，不误译）。以 `ADDR override` 行判定。
- 空战表的 `DET` / `DF` / `BOMB_TO` 手册 37.1.6 没有对应列说明，保留英文；战斗表 `X` / `Y` 是数值坐标列，不译。
- 单字母与歧义军衔码（`E` / `C` / `K` / `P` / `AM` / `MA` / `GE` / `GC` / `GI`）仍显示字母——它们与热键、设置项同形，译了会误伤别处。
- 小城镇名仍是英文（主要城市已是中文）；`.scn` 未重建，单位悬停 / 事件 / 回合摘要仍英文；百科正文在游戏内仍英文（引擎单字节限制），中文正文见 [百科中文版](https://github.com/Pig9013/WITE2_CN/blob/main/docs/百科中文版_v1.6.0.md)。
