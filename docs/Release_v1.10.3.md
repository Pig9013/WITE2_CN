# Release v1.10.3（2026-11-19）

## 这次修好了什么

**「目录含有文件链接，请将汉化包放到普通文件夹」误报。** 玩家（1.9.15）的 Steam 库被「电脑管家」迁移过，原来的 `c:\program files (x86)\steam` 变成一个指向 D 盘的目录联接（junction）。启动器从游戏目录往上检查时碰到这个联接，就当成「目录里有链接」拒绝启动，而报错却说「请将汉化包放到普通文件夹」——问题在游戏路径，不在汉化包，玩家无法据此自救。他把真实路径 `D:\电脑管家迁移文件\steam\steamapps\common\Gary Grigsby's War in the East 2` 手写进设置后就好了。

v1.10.3 起：启动器先用 `GetFinalPathNameByHandleW` 把游戏目录还原成真实路径再继续，日志写 `游戏目录经链接解析：<原> → <真实>`；只有**游戏目录内部**真有链接时才拦（那会重复复制或递归），提示也改成「游戏目录内部含有文件链接，无法安全复制：<路径>」。`--where` 额外输出 `GAME 真实路径 ...`，远程排查更快。

## 这次变了什么

- 只换启动器 `WitE2CN.exe`：词典仍 74,489 条，四语言包、字体、场景 CSV、`WitE2CN_Text.dll` 与 v1.10.2 字节一致，checksums 未变。
- 新增 `RealPath()`（`mod\src\Launcher.cs:105-128`）、`Files()` 提示改准（135-136）、`Prepare()` 解析并在日志留痕（498-503）、`--where` 多一行真实路径。
- 设计取舍：祖先联接透明放行，树内链接仍拦。
- 排查与复现记录：[docs/链接目录误报_v1.10.3.md](链接目录误报_v1.10.3.md)。

## 怎么看本版生效

- 启动器标题显示 `1.10.3` 即为本版。
- 游戏目录被搬家工具改成了联接时，`logs\launcher.log` 会出现 `游戏目录经链接解析：… → …`，随后照常「中文版资源准备完成 / 中文已接入」。
- 路径没有联接时日志与 v1.10.2 完全一致，不会多出这一行。
- `WitE2CN.exe --where` 会写 `GAME <路径>`，被解析过时再多一行 `GAME 真实路径 <路径>`。

## 遇到旧版报这个错怎么办

v1.10.2 及更早版本：把真实路径写进 `mod\settings.json` 的 `game_path`，或带参数 `WitE2CN.exe --game "<真实路径>"` 启动；不需要重装或移动汉化包。
