# 繁体语言包（台湾 / 香港 / 澳门）说明

> v1.9.0 起，汉化包同时提供四套语言包：简体中文（中国大陆）、繁體中文（台灣）、繁體中文（香港）、繁體中文（澳門）。
> 简体底本一字未改；繁体由简体按地区标准转换生成，四套语言包的键（英文原文）完全一致。

## 一、结论

**可行，已实现，但边界要讲清楚。**

| 部分 | 结论 |
|---|---|
| 字形/地区用字转换 | 可行。OpenCC `s2tw` / `s2hk` 一次转完 72,386 条，逐条守卫零失败 |
| 转换后的系统性错字 | 可行。加一层修正层，149 条（佈/併/瞭/周/占 五类），已清零 |
| 字体 | 可行。各语言包独立子集，缺字 0（2,271～2,428 字形） |
| 启动器切换 | 可行。首次启动选语言，记住到 `settings.local.json`，`--variant` 可覆盖 |
| 词汇层地区化 | **未做**。義大利/坦克/檔案 这类用词差异需要逐条人工裁决，见 §六 |
| 实机验证 | **未做**。工程侧不启动游戏，繁体显示效果以用户实机为准 |

## 二、转换层：为什么用 s2tw / s2hk，不用 s2twp

四套语言包共用同一份简体底本，只转值、不转键：

| 语言包 | 转换配置 | 说明 |
|---|---|---|
| zh-CN | 无 | 简体底本原样 |
| zh-TW | `s2tw` | 台湾正体字形（裡/著/麵/為） |
| zh-HK | `s2hk` | 香港《常用字字形表》用字（裏/着/麪/衞/羣/説） |
| zh-MO | `s2hk` | 澳门沿用香港字形表；澳门专用词走覆盖层，目前为零条，因此导出与 zh-HK 逐字节相同 |

**不用 `s2twp`**：它的短语表会把专有名词当常用词换掉，实测 4,000 条抽样里 35 条被污染：

| 原文 | s2twp 输出 | 问题 |
|---|---|---|
| Bitterfeld 比特費爾德 | 位元費爾德 | bit field |
| Burgas 布爾加斯 | 布林加斯 | boolean |
| Tukum 圖庫姆斯 | 相簿姆斯 | album |
| 旅級集群 | 旅級叢集 | cluster |

这与本项目铁律「专名不得按字面义直译」直接冲突，所以台湾也用只做字形、不做换词的 `s2tw`。

## 三、修正层：149 条

OpenCC 的短语表本身会在这五处把常用字换错（都是 1:1 换字，不改长度）。规则只做高置信度替换，并先保护白名单词：

| 类别 | 错误 | 正确处理 | 白名单（不动） | 条数 |
|---|---|---|---|---|
| 布/佈 | 佈雷達、佈列斯特、佈雷斯勞 | 布雷達、布列斯特、布雷斯勞（音译保留「布」） | 宣佈、公佈、發佈、分佈、散佈、頒佈、佈置、佈防、佈設、佈局、佈告、佈滿、遍佈、密佈、佈陣、佈署 | 73 |
| 并/並/併 | 退出軸心國**併**成為 | 退出軸心國**並**成為 | 合併、併吞、兼併、併購、併入、併案、歸併、收併、併合、併攏、併發症 | 52 |
| 了/瞭 | 參與**瞭**解救、使用**瞭**解散 | 參與**了**解救、使用**了**解散 | 瞭解、明瞭、一目瞭然 | 22 |
| 周/週 | 幾周後、%d 周後 | 幾週後、%d 週後 | 周圍、周邊、四周、周年、周旋 | 18 |
| 占/佔 | 目標**占**領回合 | 目標**佔**領回合 | — | 1 |

命中数：zh-TW / zh-HK / zh-MO 各 149 条。

## 四、字体

| 语言包 | 底本 | 字形数 | 文件 |
|---|---|---|---|
| zh-CN | 微软雅黑 msyh.ttc | 2,428 | 534 KB |
| zh-TW / zh-HK / zh-MO | 微软正黑体 msjh.ttc | 2,271 / 2,273 / 2,273 | 542 / 543 / 543 KB |

- 两个底本的 unitsPerEm 都是 2048，与简体版一致；补字源（Deng/arial/ebrima/malgun）也都在 2048 这一档（SimHei 是 256，合并会崩，禁止使用）。
- 表集与简体版完全相同：只保留 `glyf/cmap/head/hhea/maxp/OS-2/hmtx/loca/name/post`，丢掉 GSUB/GPOS/VDMX/hdmx/hinting。保留这些表会让字体大三倍，而引擎逐字光栅化根本不整形。
- 缺字检查：四个语言包全部 0 缺字。

## 五、启动器与载荷

    mod/
      payload/
        translations.json           简体底本（构建源，供 finalize 守卫用）
        overlay/                    简体 overlay（字体、Info CSV、Scen 文本）
        variants/
          zh-CN/translations.bin
          zh-TW/translations.bin + overlay/（字体、Info CSV、Scen 文本）
          zh-HK/...   zh-MO/...
        package.json                含 languages / default_language
        checksums.json              92 个文件（不含活动槽）

- 文本钩子固定读 `payload/translations.bin`，且只在注入时读一次。因此**活动槽由启动器在启动前物化**：从 `payload/variants/<code>/translations.bin` 复制过来（哈希相同则跳过）。
- 繁体语言包先复制简体 overlay，再用变体 overlay 覆盖（字体、`Dat/Info/*.csv`、`Dat/Scen/*.txt`）。
- 首次启动没有记录时弹语言选择框；勾选「记住」写入 `settings.local.json`。以后可直接：

      WitE2CN.exe --variant zh-TW
      WitE2CN.exe --variant tw          （别名：cn / tw / hk / mo）

- 启动器标题会带语言名：`WitE2 CN 中文版 v1.9.0 · 繁體中文（台灣）`。
- 离线自检（不启动游戏）：

      WitE2CN.exe --verify      只校验 checksums
      WitE2CN.exe --selftest    校验 + 逐套语言包物化比对

## 六、台湾 / 香港差异

按 HKVariants 转换后，zh-TW 与 zh-HK 有 **4,084 条**不同，差异字对与条数：

| 台湾 | 香港 | 条数 | 例 |
|---|---|---|---|
| 衛 | 衞 | 2,324 | 近衛 → 近衞 |
| 群 | 羣 | 1,281 | 集團軍群 → 集團軍羣 |
| 啟 | 啓 | 868 | 未啟用 → 未啓用 |
| 裡 | 裏 | 499 | 這裡 → 這裏 |
| 戶 | 户 | 419 | 登陸戶 → 登陸户 |
| 著 | 着 | 163 | 穿著 → 穿着 |
| 脫 | 脱 | 104 | 脫離 → 脱離 |
| 溫 | 温 | 66 | 溫帶 → 温帶 |
| 銳 | 鋭 | 59 | — |
| 說 | 説 | 29 | — |
| 臺 | 台 | 21 | 上臺 → 上台 |
| 閱 | 閲 | 13 | — |

这些正是香港教育局《常用字字形表》与台湾正体字形表分家的地方；转换只改字，不改字形轮廓。

**字形轮廓的边界**：本机没有港版字体（无 Noto Sans HK / 华康香港字形），繁体三套都用微软正黑体的轮廓渲染。所以「说」在 HK 包里是 `説`（码位正确），但笔画轮廓仍是台湾版写法。要做到港版轮廓，需要自带一套 HK 字体再子集化——这一步没做，属于已知限制。

## 七、词汇层：没有做，也不该机器做

繁体转换只做**字形与地区用字**，不做**换词**。下面这些用词差异仍然是简体版的写法：

| 简体底本用词 | 台湾常用 | 语料条数 |
|---|---|---|
| 坦克 | 戰車 | 2,444 |
| 文件 | 檔案 | 566 |
| 意大利 | 義大利 | 415 |
| 信息 | 資訊 | 82 |
| 伞兵 | 傘兵 | 46 |
| 鼠标 | 滑鼠 | 18 |
| 发动机 | 引擎 | 11 |
| 新西兰 | 紐西蘭 | 10 |
| 数据库 | 資料庫 | 9 |
| 沙特 | 沙烏地 | 6 |
| 澳大利亚 | 澳洲 | 5 |
| 网络 | 網路 | 4 |
| 软件 | 軟體 | 3 |

另有音译差异（斯大林/史達林、朱可夫/朱可夫、克罗地亚/克羅埃西亞 vs 克羅地亞）——这类要看地区出版物惯例，机器批量替换只会把「战车」误换到「战车」之外的地方。

按本项目一贯纪律：**宁可留白，不批量替换**。需要地区化时，走覆盖层：

`glossary/variants_overrides.json`

    {
      "zh-TW": {
        "简体底本的整条译文": "台湾版整条译文"
      },
      "zh-HK": {},
      "zh-MO": {}
    }

- 键是**简体译文的完整字符串**（不是英文原文），值是该语言的最终译文；
- 命中即整条替换，转换层与修正层都不再作用；
- 改完跑 `python integration/build_variants.py` → `python mod/finalize.py` → `python mod/publish.py`。

## 八、守卫与审计

构建时逐条检查（任一条失败即中止构建）：

| 守卫 | 判据 | 结果 |
|---|---|---|
| 键集合 | 四套语言包键必须与简体逐条相同 | 72,386 / 72,386 / 72,386 / 72,386 |
| 骨架 | 去掉汉字后的拉丁、数字、标点必须逐字不变 | 0 失败 |
| 长度 | 转换是 1:1 换字，长度不得变化 | 0 失败 |
| 括号 | 简体平衡则繁体也必须平衡 | 0 失败 |
| 格式占位符 | `%d`、`%s`、`%%` 序列必须一致 | 0 失败 |
| 替换字符 | 值里不得出现 U+FFFD | 0 失败 |
| 字形覆盖 | 字体 cmap 必须覆盖该包全部字符 | 缺字 0 |
| overlay 结构 | Info 6 表 + Scen 12 篇，行列数与简体一一对应 | 通过 |
| checksums | 92 个文件 | 全通过 |
| 启动器物化 | 四套语言包轮转复制 + 哈希比对 | `--selftest` 通过 |

反向回译抽查：把繁体包用 `tw2s`/`hk2s` 转回简体，与简体底本比对，只有 132 / 103 条不一致——逐条查看，全部是简体底本本身混入了繁体字（如 `别列津纳戰役`、`第44步兵师克雷莫纳師`），繁体包反而顺手规范了。

## 九、顺带发现的两个简体底本缺陷（未修）

1. **32 条简体译文混入繁体字**：`第44步兵师克雷莫纳師`、`别列津纳戰役`、`铁山脈`、`凯代尼亞` 等。繁体包已按地区标准规范；简体包保持原样，建议后续在简体层修掉。
2. **4 条键含替换字符 U+FFFD**：`B�tasz�k`、`Hajd�szoboszl�`、`V�rpalota`、`Kemij�rvi`（匈牙利语地名被 cp1252 洗过）。这些键在游戏里永远匹配不上，属死条目，需要重新补正确键。

## 十一、作者立场提示（仅繁体版）

繁体三套语言包有两处作者立场内容，简体版都没有：

**1）首次启动的一次性提示**（v1.9.2 起）

标题「MOD 作者立場」，正文三段：

    本漢化包由作者個人製作。
    作者立場：堅持一個中國原則，支持「一國兩制」方針。
    以上僅為作者個人立場，不代表遊戲開發商與發行商，也不影響漢化包的下載與使用。

只有一个按钮「我已明確知曉 mod 作者立場」。**不要求同意、不阻断启动**：点按钮继续，按 Esc 继续，点右上角关闭也继续。

- 只显示一次：点过之后往 `settings.local.json` 写 `stance_seen: true`；想再看一次，把该键删掉即可；
- 想看效果又不想启动游戏：`WitE2CN.exe --stance-preview`；
- 简体版不显示，也不写标记。

**2）进度窗口的常驻一行**（v1.9.1 起）

署名区下方固定显示：

    作者立場：堅持一個中國原則，支持「一國兩制」方針。
    以上為作者個人立場，不代表遊戲開發商與發行商。

- 触发条件：启动器选中的语言不是 `zh-CN`；
- 字体：Microsoft JhengHei UI 9pt，与繁体包字形一致；
- 只影响启动器 UI：四套语言包译文、字体、checksums 均不受影响。

## 十、复现

    python integration\build_variants.py     # 生成四套语言包 + 字体（需要 opencc、fontTools）
    python mod\finalize.py                   # 语言包守卫 + checksums（92 文件）
    python mod\publish.py                    # 发布到安装目录并校验
    WitE2CN.exe --selftest                   # 离线自检四套语言包

依赖：`opencc`（Python 绑定）、`fontTools`；字体取 `C:\Windows\Fonts` 下的 msyh/msjh（2048 upem）。
